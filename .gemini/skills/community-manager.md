# Skill: Community Manager — Contenido para Redes

## Descripción
Genera contenido para redes sociales, textos de difusión y material de comunicación del proyecto Geometrías Precolombinas. Adaptado para Instagram, X (Twitter), portafolios y comunicados de prensa.

## Cuándo usar
- Para publicar avances del proyecto en redes sociales
- Para preparar textos de presentación en convocatorias
- Para crear hilos educativos sobre las culturas precolombinas
- Para generar captions de videos/imágenes de las escenas

## Instrucciones

### 1. Identidad de voz

| Aspecto | Definición |
|---|---|
| **Tono** | Poético-técnico, accesible pero no superficial |
| **Persona** | Primera persona singular (yo, Jean / @jeanmadara) |
| **Idioma principal** | Español latinoamericano |
| **Idioma secundario** | Inglés (para alcance internacional) |
| **Emojis** | Uso moderado, con intención — preferir: 🔺 △ ◯ ▪ ✦ ⬡ |
| **Hashtags** | Al final del post, nunca inline |

### 3. Temas de contenido recurrentes

| Categoría | Ejemplos de posts |
|---|---|
| **Proceso** | "Cómo traduzco una vasija funeraria en código p5.js" |
| **Pieza destacada** | Zoom a una cultura/artefacto específico con su historia |
| **Técnico** | Explicar un efecto (Ken Burns, Perlin noise, crossfade) |
| **Reflexión** | Relación entre código y ofrenda, algoritmo y ritual |
| **Behind the scenes** | Screenshots de código, errores, iteraciones |
| **Dato arqueológico** | Mini-hilo sobre una cultura (Valdivia, Tolita, etc.) |
| **Resultado visual** | Video o GIF de una escena en ejecución |
| **Milestone** | Nueva escena terminada, exhibición, premio |

### 4. Calendario sugerido de publicación

| Día | Tipo de contenido | Formato |
|---|---|---|
| Lunes | Proceso / Behind the scenes | Imagen + caption |
| Miércoles | Pieza destacada o dato arqueológico | Carousel o hilo |
| Viernes | Resultado visual | Video/Reel |
