---

## Notas de Operación

1. **Iniciar escena**: Abrir HTML → `F11` (pantalla completa) → la escena arranca automáticamente
2. **Audio**: Sonic Pi se ejecuta en paralelo desde un segundo computador (o el mismo). Sincronización manual por cue visual.
3. **Transiciones**: Las transiciones entre escenas se hacen manualmente cerrando/abriendo pestañas, o con video pregrabado
4. **Emergencia**: Recargar la página reinicia la escena desde el frame 0
5. **Si se usa video pregrabado**: Audio se mezcla en post-producción con las texturas de Sonic Pi renderizadas a WAV
